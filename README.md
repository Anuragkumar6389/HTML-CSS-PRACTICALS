## 📌 1. Project Overview

Welcome to my **HTML & CSS Development Lab Practicals** repository.

This repository contains my practical assignments Lab for the **BCS554 – HTML & CSS Development Lab**, completed as part of my Bachelor of Technology (B.Tech) in Computer Science and Engineering.

The main purpose of this project is to develop a strong foundation in web development by learning and implementing HTML5 and CSS3 concepts through practical exercises.

All practical assignments are organized into 15 individual lab folders. Each folder contains the required source code, stylesheet, practical documentation, and screenshot of the output.

The project follows a simple and organized structure to make the code easy to understand, execute, and maintain.

## 🎯 2. Project Objectives

The major objectives of this practical project are:

- To understand the fundamentals of web development.
- To learn the structure and syntax of HTML5.
- To create structured web pages using HTML elements and attributes.
- To apply CSS3 properties for designing attractive web pages.
- To understand text formatting, colors, backgrounds, borders, and spacing.
- To practice different types of HTML lists and tables.
- To understand hyperlinks, images, and multimedia integration.
- To create forms using HTML input elements.
- To understand CSS selectors and styling techniques.
- To practice page layouts and positioning.
- To learn responsive web design concepts.
- To develop practical coding and debugging skills.

## 💻 6. How to Run the Project

Follow these steps to execute any practical.

### Step 1: Open the Project

Open Visual Studio Code.

### Step 2: Open the Practical Folder

Select the required practical folder, such as `Lab1`, `Lab2`, or `Lab15`.

### Step 3: Open the HTML File

Open the `index.html` file.

### Step 4: Run with Live Server

- Right-click on `index.html`.
- Select **Open with Live Server**.
- The output will open automatically in your default browser.

### Step 5: View the Output

Check the webpage in your browser and verify the HTML structure and CSS styling.

### Alternative Method

You can also open the `index.html` file directly in Google Chrome or another web browser without using Live Server.
