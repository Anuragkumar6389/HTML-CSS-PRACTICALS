Task 1: Create a GitHub Account

GitHub is an online platform used to store and manage source code using Git.

  1. Visit the GitHub website.
  2. Click on Sign Up.
  3. Enter your email and password.
  4. Verify your account.
  5. Sign in to GitHub.
Visit GitHub

Task 2: Create a GitHub Repository

Steps to create a new repository:

  1. Sign in to your GitHub account.
  2. Click on the New Repository option.
  3. Enter a repository name.
  4. Select Public or Private.
  5. Click Create Repository.

Task 3: Basic Git Commands

Git commands used to manage a project:

git --version

git config --global user.name "Your Name"

git config --global user.email "your@email.com"

git init

git status

git add .

git commit -m "Initial commit"

Conclusion

In this practical, I learned how to create a GitHub account, create a repository and use basic Git commands.
